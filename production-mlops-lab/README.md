# Heart Disease MLOps Platform

A production-style machine learning and MLOps learning project for
heart disease risk classification using the UCI Heart Disease dataset.

## Disclaimer

This project is for educational and engineering demonstration purposes.
It is not a clinical diagnostic system and must not be used for medical
decision-making.

## Project objectives

- Reproducible data ingestion and validation
- Feature engineering and model training
- MLflow experiment tracking
- Model evaluation and quality gates
- ONNX export and ONNX Runtime validation
- FastAPI inference
- Docker packaging
- GitHub Actions CI/CD
- Google Artifact Registry
- Google Kubernetes Engine
- Prometheus and Grafana monitoring
- Data drift and model performance monitoring

## Current status

Stage 2: repository and project definition.

## Data source

UCI Heart Disease dataset:

https://archive.ics.uci.edu/static/public/45/heart+disease.zip

The dataset license and attribution requirements must be reviewed before
redistribution or publication.

## Production warning

The model output is an experimental prediction. It does not constitute
medical advice, diagnosis, or treatment guidance.
